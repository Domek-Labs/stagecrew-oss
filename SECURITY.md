# Security

Report a vulnerability privately via **Security → Report a vulnerability** on this repository, not as a public issue.

stagecrew is a set of Markdown skills and repo-internal checks; it runs no service of its own. What counts as a vulnerability here is mostly a skill that could make an agent leak a secret, push to a branch it must not touch, or act outside the repo it was started in. A fix ships with the next release; you are credited unless you ask not to be.
